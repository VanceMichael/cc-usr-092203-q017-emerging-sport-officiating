# 新兴项目设备场地认证

认证新兴运动项目的设备、场地、海况和医疗保障是否满足开赛条件。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料反映以下领域事实：

- 新增项目采用差异显著的评分和比赛方式，四类项目分别适用独立验收标准，不得使用通用验收表
- 虚拟跆拳道依赖头显与动作传感器，需定期校准并监控漂移
- 板式网球场地依赖玻璃墙与出界安全区，玻璃损伤须立即处置
- 冲浪比赛面对实时海况，环境阈值决定能否开赛
- 综合格斗场地涉及围绳、地垫与现场医疗救护配置
- 冲浪等项目包含主观评分并可能关联奥运资格

## 资料结构

- `sports`：各项目的设备型号与校准计划、场地尺寸与安全设施、安全标准、环境阈值、医疗资源
- `inspections`：检查记录，数据与照片均带采集时间
- `work_orders`：维护工单，换件或临时修复只影响对应设施，场馆人员只处理自身工单
- `incidents`：设备跨场借用、传感器漂移、玻璃损伤、海况突变、救护人员缺席等事件及其传播的受影响赛程
- `certifications`：认证结论，含标准版本、有效期与签署人，过期证书不得继续放行
- `decisions`：开赛、延迟或取消决定，可回溯到当时有效的标准、检查证据与签署人

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、事实、约束以及各项目档案、检查、工单、事件、认证与决定均保持完整，跨记录引用闭合。仓库不保存账号、密钥、连接串或真实身份资料。
